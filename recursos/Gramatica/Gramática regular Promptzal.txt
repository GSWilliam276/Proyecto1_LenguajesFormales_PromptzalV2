Gramática regular — Analizador léxico PromptZal

Cada producción corresponde al AFD diseñado para esa misma categoría de token (ver recursos/afd/afd.dot y afd.png). La notación sigue el formato visto en clase: A → aB o A → a, donde las minúsculas son terminales (símbolos del alfabeto de entrada) y los símbolos entre < > son no terminales.

Convenciones usadas:

l = una letra cualquiera (a-z, A-Z)
d = un dígito cualquiera (0-9)
c = cualquier carácter del alfabeto excepto los símbolos que cierran explícitamente esa categoría (se detalla en cada caso)
1. Identificador / palabra reservada / comando / conector de palabra

Comparten el mismo AFD (método leerPalabra()); la clasificación en PALABRA_RESERVADA, COMANDO_IA, CONECTOR o IDENTIFICADOR se decide "al vuelo" consultando una tabla una vez terminada la acumulación, no dentro de la gramática misma.

<PALABRA> → l <PALABRA>
<PALABRA> → l
2. Símbolo de un carácter ( = + { } ( ) , )

Sin lazo: se resuelve en un solo paso. La clasificación entre OPERADOR y DELIMITADOR también se decide al vuelo, según cuál símbolo fue.

<SIMBOLO> → =
<SIMBOLO> → +
<SIMBOLO> → {
<SIMBOLO> → }
<SIMBOLO> → (
<SIMBOLO> → )
<SIMBOLO> → ,
3. Conector flecha ->

Dos terminales fijos en secuencia, sin lazo ni pasos intermedios.

<FLECHA> → - >
4. Número (entero / decimal)
<NUMERO> → d <NUMERO>
<NUMERO> → d
<NUMERO> → d . <FRAC>
<FRAC>   → d <FRAC>
<FRAC>   → d
5. Cadena "..."

c aquí = cualquier carácter distinto de " y de salto de línea.

<CADENA>            → " <CONTENIDO_CADENA>
<CONTENIDO_CADENA>  → c <CONTENIDO_CADENA>
<CONTENIDO_CADENA>  → "
6. Directiva (@modelo, @rol, @formato)

El cierre no usa un símbolo explícito: termina apenas deja de acumularse una letra/dígito/guion bajo. La validación contra la lista de directivas permitidas (modelo, rol, formato) se hace al vuelo, fuera de la gramática.

<DIRECTIVA>            → @ <CONTENIDO_DIRECTIVA>
<CONTENIDO_DIRECTIVA>  → l <CONTENIDO_DIRECTIVA>
<CONTENIDO_DIRECTIVA>  → l
7. Comentario de línea //

No genera token; c = cualquier carácter distinto de salto de línea.

<COMENTARIO_LINEA> → / / <CONTENIDO_LINEA>
<CONTENIDO_LINEA>  → c <CONTENIDO_LINEA>
<CONTENIDO_LINEA>  → \n
8. Comentario de bloque /* */

No genera token; c = cualquier carácter que no forme parte de la secuencia de cierre */. Si el archivo termina sin encontrar */, esto ya no lo describe la gramática (que solo modela el lenguaje válido); ese caso lo maneja la recuperación de errores en el código Java, y se documenta aparte en el manual técnico.

<COMENTARIO_BLOQUE> → / * <CONTENIDO_BLOQUE>
<CONTENIDO_BLOQUE>  → c <CONTENIDO_BLOQUE>
<CONTENIDO_BLOQUE>  → * /
